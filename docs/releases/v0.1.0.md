# PiHuo v0.1.0

## English

### Summary

First tagged desktop release of **PiHuo** (then branded PiHuo): a local multi-agent command center. A Supervisor **Leader** plans and delegates to ACP workers (Claude Code, Codex, OpenCode, Registry agents) running on your machine, tracked in one desktop app.

### Highlights

- **Leader chat & delegation** — role-aware jobs (`plan` · `coder` · `review` · `test` · `research` · `general`) with live worker cards
- **Approvals** — Session permission modes (`default` / `auto`) for ACP permission requests in chat and the side panel
- **ACP Registry** — bundled offline catalog; prepare → trust → authenticate before dispatch
- **Models & secrets** — Leader models and encrypted local API keys; built-in providers + custom gateways
- **Projects & sessions** — local project roots, multi-session chat, optional ACP session resume
- **Desktop shell** — PiHuo brand, dual-pane layout, settings overlays, EN/ZH UI

### Changes in this release

- Chat **process fold** after completion (thinking / work summary collapsed; final reply outside the fold)
- Settings UX: General scroll, motion preference, Worker execution settings, About / open-source credits
- README **EN + ZH** screenshot sets (CDP capture) and a showcase demo seed project
- Composer pending-changes viewer and chat code-block improvements
- Release pipeline for macOS arm64 + Linux x64 installers (Windows package matrix temporarily disabled)

## 中文

### 摘要

**Pi活儿** 首个正式 tag 桌面发版（当时品牌为 PiHuo）：本机多智能体指挥台。Supervisor **Leader** 负责规划与委派，ACP Worker（Claude Code / Codex / OpenCode / Registry）在本地执行，统一在桌面端跟踪。

### 产品能力

- **Leader 对话与委派**：按角色派发 Job（`plan` · `coder` · `review` · `test` · `research` · `general`），Worker 卡片实时流式展示
- **审批**：Session `default` / `auto` 权限模式；Chat 与侧栏展示 ACP 权限请求
- **ACP Registry**：完整 Catalog 随包；prepare → trust → authenticate 后再调度
- **模型与密钥**：Leader 模型与加密本地 API Key；内置 Provider + 自定义网关
- **项目与 Session**：本地项目根、多 Session、可复用 ACP Session（在 Agent 支持时）
- **桌面壳**：Pi活儿 品牌、双栏布局、设置全页、中英 UI
